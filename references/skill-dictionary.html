📘 Codex에서 스킬 쓰는 법 · 추천 흐름 (클릭)
  • 호출: 대화창에 $스킬이름 입력. 설치된 목록은 /skills. 작업 내용이 스킬 설명과 맞으면 자동으로 불려오기도 함
  • 설치 위치: 프로젝트용 .agents/skills/ · 개인용 ~/.agents/skills/. 설치 후 Codex 재시작
  • 중복 주의: 같은 스킬을 플러그인과 npx skills로 두 번 설치하지 않기
  • 안전: 설치 전에 SKILL.md를 한 번 읽어보기. 스타 수는 인기 지표일 뿐 품질 보증이 아님
  • 새 기능: $grill-me → $to-spec → $to-tickets → $implement-spec → $code-review → $pr
  • 버그: $diagnosing-bugs → $tdd(재발 방지 테스트) → $verification-before-completion
  • 디자인: $ui-ux-pro-max(방향 잡기) → 구현 → $impeccable critique → polish → audit
  • 세션 정리: 대화가 길어지면 $handoff, AI가 이상했던 세션 뒤엔 $retro
